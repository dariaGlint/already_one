# .gitignore汎用修正ワークフロー作成計画

## ゴール
Unityプロジェクトのルートフォルダが任意のサブディレクトリ（`src`, `Client`, `App` 等）に移動された場合に対応できるように、`.gitignore` 修正ワークフローを汎用化する。

## ユーザーレビューが必要な事項
- 特になし

## 変更内容

### ワークフローの汎用化
#### [MODIFY] .agent/workflows/update-gitignore-src.md
- **変更前**: `src/` 固定でパスを置換。
- **変更後**:
    - 依頼内容やディレクトリ構造から `[TARGET_DIR]` を特定。
    - 特定したディレクトリをプレフィックスとして `.gitignore` のパスに追加するロジックに変更。
    - 日本語での記述に変更。
    - Descriptionに「.gitignoreの対象ディレクトリを[DIR]に更新して」等のトリガーフレーズを追加。

## 検証計画
### 手動検証
- ワークフローファイルの内容が意図通り更新されているか確認する。
